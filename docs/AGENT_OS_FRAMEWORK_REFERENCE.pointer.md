# Agent OS — Framework Reference (Pointer)

The canonical, **non-editable** Agent OS framework reference is stored in the
`taifoon-intel` repository and serves as the **backoff context** for evolving
both `taifoon-intel` and `open-mamba` into a productized framework of
re-shareable components targeting commercial systems (SAP, n8n.io, etc.).

- Canonical path: `taifoon-intel/docs/AGENT_OS_FRAMEWORK_REFERENCE.md`
- Edit policy: read-only / frozen. Do not mutate. If new guidance is needed,
  add a NEW dated reference next to it — never edit in place.
- Stored: 2026-05-06 by MB (maciej@t3rn.io).

`open-mamba` components (mamba-bus, mamba-lake, portfolio sidecar, etc.) are
expected to map onto the BUILD / RUN / GOVERN / EVOLVE component grid defined
in that reference when packaged for commercial productization.
